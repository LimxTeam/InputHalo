This is a Preview build.
Requires Windows 10 version 1809 or later / Windows 11, x64, and a Vulkan 1.4
capable graphics driver. The Vulkan SDK is not required. Graphics drivers are
not included; the C++ runtime is statically linked.

Installs for the current user without administrator privileges. Exit InputHalo
from its system tray menu before upgrading. Closing Settings only hides it.
Installation and removal preserve settings, profiles and logs in
%LOCALAPPDATA%\InputHalo.

Cursor tracking includes independent position sampling on the normal desktop.
Overlays pause on the Windows secure desktop and resume when it is accessible.
