# 配置方案、排除规则与标注

## 配置方案

“配置方案”页面提供教学演示、会议简洁、录屏清晰三个内置方案。
单击选中后“应用方案”生效。内置方案不能删除，可以另存为自定义方案。

- 另存当前：文件名即方案名，默认位置为 `%LOCALAPPDATA%\InputHalo\profiles`；
  如果选择其他目录，也会在本地方案库保留一份副本。
- 导入：读取 InputHalo JSON 文件，检查格式、字段类型、大小（最多 256 KiB）和嵌套深度。
  导入后先加入列表，点击应用后才修改当前显示；同名导入创建带序号的副本。
- 导出：导出列表中选中的方案。要导出当前未保存的设置，请先“另存当前”。
- 删除：仅支持本地自定义方案，按钮再点一次确认；不会删除原始外部导入文件。
- 本地最多 128 个自定义方案。无效文件不会执行，也不会被当作可用方案加载。

方案只切换操作提示、光标、激光、标注和主题色。语言、开机启动、启动收起及排除规则是本机偏好，
应用方案不会覆盖这些设置。导出不携带实际本机排除列表；旧的完整 settings.json 可以导入为显示方案。
配置仍自动保存，重新启动保留最后应用后的实际设置。

## 排除规则

应用排除：选择 `.exe`，保存其文件名；当该程序成为前台窗口时暂停全部提示和绘制，
切回其他应用自动恢复。按文件名忽略大小写匹配，同名的其他路径程序也适用。
切换到排除应用会清空瞬时输入与标注状态；离开后需要重新按下标注快捷键。
切换检测由主消息循环完成，空闲时最多约 250 ms 后更新；Windows 不允许读取进程名称时无法匹配。
应用排除不是密码检测或录屏保护。

快捷键隐藏：点击“录入快捷键”，按下要隐藏的键盘组合键；Esc 取消。
仅隐藏精确匹配的屏幕键帽，例如隐藏 Ctrl+C 不会同时隐藏 Ctrl+Shift+C。
规则不会拦截按键，也不会使激光、标注等快捷键失效。可从列表单独移除，最多 128 条。
点击不同栏目或切换窗口会取消录制。

## 标注

在“标注”页选择矩形、箭头或椭圆。默认保持 `Ctrl+Shift+Space`，左键拖动连续绘制。
箭头从按下位置指向松开位置；矩形和椭圆支持任意方向拖动。
保持标注快捷键时单击右键撤销最后一笔；正在绘制的一笔也可撤销。
松开激活组合键任意必要按键后清空所有标注。每次保持期间最多 64 笔，撤销后可以继续绘制。
右键被标注层接收，不需要把 Ctrl+Z 发送给后台文档。

本轮只进行了编译、启动与用户要求的内存数据读取，未运行自动化或交互功能测试。
